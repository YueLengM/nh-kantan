## 功能

- 可自定义股市钱包物品兑换列表
- 可配置股市行情算法
- 智能算法量化机构（包含做市商、趋势交易、动量交易等真实量化交易思路）
- 真实的撮合算法
- 14日期权（仅可做买方）
- 接近真实的交易体验（有滑点、部分成交、可挂单止盈止损）
